# m_learning

C++ Mobile Learning Application with the integration with Learning Management System and Gamification with AI chatbot. 

## Getting Started

**FEATURES**
1. Interactive C++ Lessons: Structured lessons that cover C++ programming basics and advanced topics.
2. Quizzes & Assessments: Evaluate learning through quizzes with immediate feedback and progress tracking.
3. Gamification: Engage learners with a rewards-based system, achievements, and leaderboards
4. AI Chatbot: Provides personalized support, answers questions about C++, and offers learning recommendations.
5. LMS Integration: Tracks user progress, provides access to learning resources, and manages user accounts.

**TECHNOLOGY STACK**
1. Flutter: Frontend mobile framework for building cross-platform apps.
2. Dart: Programming language used for developing Flutter apps.
3. Firebase: Backend for user authentication, data storage, and real-time sync.
4. C++: Core language for teaching programming concepts
5. AI Chatbot: Custom-built using AI/ML models to assist user
6. Learning Management System: Integrates with the app to deliver personalized learning and track student data

   **INSTALLATION**
1. Clone the repository 
2. in the terminal write "flutter pub get"
3. flutter run 


**FEATURES IN DETAIL**
1.  C++ Interactive Learning Modules
The app includes step-by-step tutorials and coding challenges. Each module covers core C++ concepts such as variables, loops, conditionals, object-oriented programming, and more. Quizzes are included at the end of each module to reinforce learning
2. Gamification System
   - **Rewards**: Users earn points for completing lessons, quizzes, and challenges
   - **Badges**: Achievements are unlocked for completing specific tasks like scoring above 80% in a quiz or completing all lessons in a module.
   - **Leaderboards**: Display top learners based on points and quiz performance
3. AI Chatbot
- Answering questions related to C++ programming.
- Providing quick fixes and tips for coding errors.
4. LMS Integration
  -** User Authentication**: Handles user sign-up and login through Firebase.
  - **Progress Tracking**: Syncs student progress with the LMS backend, allowing teachers to monitor individual performance.
